# exp005: 攻撃・番終了前に可能な行動を使い切る

## 目的

メイン行動の選択時に、攻撃または番終了以外の行動が残っている間はそれらを優先し、可能な準備行動を使ってから攻撃または終了する方針を評価する。

## 仮説

- 「番を終える」を早く選ばず、エネルギー付与・カード使用・進化・特性・にげるなどを先に行うと、exp001のmax-count randomより有利になる。
- 行動候補の中ではランダムに選び、効果中のカードや対象の選び方はexp001と同じにすることで、ターン終了の判断を変えた影響を比較できる。

## 実装

- `experiments/exp005/agent/exhaust_agent.py`: exp005エージェント
- `experiments/exp005/agent/action_policy.py`: 準備行動を優先し、残りが攻撃または終了だけになったら攻撃を優先する方針
- `experiments/exp005/decks/exp005_deck.csv`: exp001と同一の固定デッキ
- `experiments/exp005/run_evaluation.py`: 席順を入れ替えた対戦評価

## 評価条件

- 対戦数: 100試合 / 条件
- 乱数シード: 0
- 条件: random vs random、exp005 vs random、random vs exp005、exp005 vs exp005
- デッキ: `exp005_deck.csv` 固定
- 成功基準: 全条件でエラー0件。exp005のrandom対戦勝率を席順合算で比較

## 結果

`uv run python -m experiments.exp005.run_evaluation --games 100` で評価した。

| 条件 | agent0勝利 | agent1勝利 | 完走 | 引き分け | エラー |
|---|---:|---:|---:|---:|---:|
| random vs random | 51 | 49 | 100 | 0 | 0 |
| exp005 vs random | 91 | 9 | 100 | 0 | 0 |
| random vs exp005 | 17 | 83 | 100 | 0 | 0 |
| exp005 vs exp005 | 48 | 52 | 100 | 0 | 0 |

exp005のrandom対戦は席順を合算すると174勝 / 200試合（87%）だった。
exp005同士の対戦は48対52で、目立った席順差は確認されなかった。
全400試合が完走し、エラーと引き分けは0件だった。

## 結論

準備行動を攻撃より先に行い、準備行動がなくなったら攻撃、攻撃もなければ終了する方針は、固定デッキのmax-count randomを大きく上回った。全試合で合法に動作したため、exp005を新しいローカルbaselineに昇格する。評価は固定デッキ・各条件100試合に基づく。
