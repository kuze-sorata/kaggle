# exp003: エネルギー付与優先ヒューリスティック

## 目的

`exp002`の攻撃優先方針を見直し、当該ターンにまだエネルギーを付けておらず、
手札に付与可能なエネルギーがある場合は、攻撃より先にエネルギー付与を行う。

## 仮説

- `current.energyAttached == false` の場面では、合法な攻撃よりエネルギー付与を優先した方が有利。
- エネルギー付与後は、攻撃可能なら攻撃する方がよい。
- `exp001`と同じ固定デッキを使い、行動方針だけの差を比較できる。

## 実装

- `experiments/exp003/agent/energy_agent.py`: エネルギー付与優先方針
- `experiments/exp003/decks/exp003_deck.csv`: `exp001`・`exp002`と同一の固定デッキ
- `experiments/exp003/run_evaluation.py`: random、exp002との比較評価
- エネルギーID `3` は今回の固定デッキに固有の設定

## 評価条件

- 対戦数: 100試合 / 条件
- 乱数シード: 0
- 条件: random vs random、exp002 vs random、energy-first vs random、
  random vs energy-first、energy-first vs exp002、energy-first vs energy-first
- 成功基準: 全条件でエラー0件、energy-firstの勝率と行動方針を比較

## 結果

`uv run python -m experiments.exp003.run_evaluation --games 100` で評価した。

| 条件 | agent0 | agent1 | 完走 | agent0勝利 | agent1勝利 | 引き分け | エラー |
|---|---|---|---:|---:|---:|---:|---:|
| random vs random | random | random | 100 | 52 | 48 | 0 | 0 |
| exp002 vs random | exp002 | random | 100 | 3 | 97 | 0 | 0 |
| energy-first vs random | energy-first | random | 100 | 22 | 78 | 0 | 0 |
| random vs energy-first | random | energy-first | 100 | 86 | 14 | 0 | 0 |
| energy-first vs exp002 | energy-first | exp002 | 100 | 94 | 6 | 0 | 0 |
| energy-first vs energy-first | energy-first | energy-first | 100 | 48 | 52 | 0 | 0 |

energy-firstのrandom対戦は席順を合算すると36勝 / 200試合（18%）だった。
exp002のrandom対戦は6勝 / 200試合（3%）であり、energy-firstはexp002を
大幅に上回った。全600試合でエラーと引き分けは0件だった。

平均意思決定時間は、random vs randomが約0.0000185秒、energy-first vs randomが
約0.0000231秒、random vs energy-firstが約0.0000268秒、energy-first vs exp002が
約0.0000209秒、energy-first vs energy-firstが約0.0000247秒だった。

## 結論

エネルギー付与を攻撃より優先することでexp002の攻撃優先方針は改善したが、
random baselineには届かなかった。エネルギー付与だけでは付与先や攻撃対象の
価値を評価できないため、exp001をbaselineとして維持する。次は付与先、攻撃対象、
カード効果を観測から評価する行動評価関数へ進む。
