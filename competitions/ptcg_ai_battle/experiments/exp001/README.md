# exp001 artifacts

`experiments/exp001.md` is the canonical experiment record. This directory
contains the files needed to inspect the experiment in chronological order.

- `agent/`: snapshot of the random baseline used for exp001
- `decks/`: the fixed 60-card deck used in the experiment
- `outputs/`: match results, observations, reports, and HTML replays
- `observation_schema.md`: fields observed by the agent during exp001

The reusable CABT execution and reporting code remains in `simulator/`.
