# exp002: 攻撃優先・終了回避ヒューリスティック

## 目的

`exp001`の完全ランダムAIに対して、メイン行動の選択だけに限定的な
ルールを追加し、行動の質と勝率への影響を確認する。

## 仮説

- 攻撃が合法な場面では、攻撃を優先する方がランダム選択より有利。
- 攻撃がない場面では、`終了`以外の行動を優先する方が有利。
- 初期デッキと、メイン行動後のカード選択は`exp001`と同じにすることで、
  行動方針だけの効果を比較できる。

## 実装

- `experiments/exp002/agent/heuristic_agent.py`: 攻撃優先・終了回避
- `experiments/exp002/decks/exp002_deck.csv`: `exp001`と同一の固定デッキ
- `experiments/exp002/run_evaluation.py`: 4条件の対戦評価
- `simulator/run_tournament.py`: エージェント差し替え可能な共通評価処理

## 評価条件

- 対戦数: 100試合 / 条件
- 乱数シード: 0
- 条件: random vs random、heuristic vs random、random vs heuristic、
  heuristic vs heuristic
- デッキ: `exp002_deck.csv` 固定
- 成功基準: 全条件でエラー0件、random vs randomに対して勝率と行動分布を比較

## 結果

`uv run python -m experiments.exp002.run_evaluation --games 100` で評価した。

| 条件 | agent0 | agent1 | 完走 | agent0勝利 | agent1勝利 | 引き分け | エラー |
|---|---|---|---:|---:|---:|---:|---:|
| random vs random | random | random | 100 | 62 | 38 | 0 | 0 |
| heuristic vs random | heuristic | random | 100 | 3 | 97 | 0 | 0 |
| random vs heuristic | random | heuristic | 100 | 95 | 5 | 0 | 0 |
| heuristic vs heuristic | heuristic | heuristic | 100 | 46 | 54 | 0 | 0 |

heuristicのrandom対戦は、席順を合わせると8勝 / 200試合（4%）だった。
平均意思決定時間は、random vs randomの約0.0000193秒に対して、
heuristic vs randomが約0.0000200秒、random vs heuristicが約0.0000184秒、
heuristic vs heuristicが約0.0000226秒だった。

## 結論

全400試合がエラーなく完走したため、合法手を返す安全性は維持できた。
一方で、攻撃を優先してターンを早く終える方針は、固定デッキに対して
random baselineより明確に弱かった。攻撃の合法性だけでは攻撃価値を判断できず、
エネルギー・進化・特性などのセットアップを犠牲にした可能性がある。
この結果は100試合×席順の比較に基づくため原因の断定には使わず、
exp001をbaselineとして維持する。次は「終了回避のみ」や「セットアップ優先」
を分離したアブレーションから再開する。
